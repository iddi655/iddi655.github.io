## 🧭 What ivi-analysis Does

ivi-analysis is an equity research application for SEC filings. It helps you study a public company using official filing data, point-in-time fundamentals, and a deterministic valuation model. It also includes an SEC MCP server and optional AI analyst memos.

In plain terms, the application helps you answer questions such as:

- What did this company report in its SEC filings?
- What financial numbers were available at a specific point in time?
- What does a discounted cash flow valuation show using clear inputs?
- How can an AI assistant connect to SEC filing data through a standard server?
- What would an analyst memo look like when generated from the available data?

The application is designed for end users who want a guided research workflow without building their own data pipeline.

## 📊 Point-in-Time Fundamentals

Point-in-time fundamentals show what was known at a chosen date. This matters because company reports arrive over time. A number that is available today may not have been available six months ago. ivi-analysis helps you organize filing data around the date you choose, so your research view matches the information available at that moment.

Use this part of the application when you want a cleaner view of company performance without mixing later reports into earlier periods. Select a company, choose the date or period you want to review, and open the fundamentals screen. The application presents the filing-based values in a structured layout.

## 🧮 Deterministic Valuation

Deterministic valuation means the same inputs produce the same outputs. ivi-analysis uses clear valuation inputs and a repeatable model. You can review the assumptions, change a value, and see how the result responds. This helps you compare scenarios without hidden changes between runs.

The valuation section supports discounted cash flow style thinking. A discounted cash flow view estimates what future cash flows are worth today. The application keeps the process visible so you can follow the inputs, the calculation path, and the final value. Use the valuation screen after you have reviewed the company fundamentals.

## 🔌 SEC MCP Server

The SEC MCP server is a connection layer for tools that understand the MCP standard. In simple terms, it gives an assistant or research tool a structured way to request SEC filing information. The server is part of the ivi-analysis project and is intended for users who want to connect filing data to supported assistant workflows.

Use this feature when you want an assistant to work with SEC data through a standard connection instead of manual copy and paste. The server works with the application data and filing sources described in the project.
